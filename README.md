# 🎥 Video to Obsidian Notes

> 🇨🇳 **中文简介**: 基于 Hermes Agent 的自动化工具，将视频转录为文字并生成结构化的 Obsidian 笔记。

## ✨ 核心功能

- 🎙️ **高精度转录**: 使用本地运行的 `faster-whisper` 模型，保护隐私，无需联网上传音频。
- 📝 **智能总结**: 自动提取核心观点、关键信息、行动清单，生成符合 Obsidian 规范的 Markdown 笔记。
- 📦 **批量处理**: 支持视频下载并行，转录与总结严格串行，稳定处理大批量任务。
- 🔗 **Obsidian 原生**: 自动使用 WikiLinks `[[...]]` 建立双链，文件名带日期前缀，支持索引自动更新。
- 📉 **降级策略**: 遇到反爬或下载失败时，自动基于元数据和领域知识进行推理总结。

## 🛠 技术栈

- **Agent**: Hermes Agent
- **ASR**: `faster-whisper` (Base Model, Local Execution)
- **Language**: Python 3.11
- **Target**: macOS (Apple Silicon Optimized)

## 🚀 如何使用

1. 确保你的环境中安装了 `faster-whisper`。
2. 将本仓库内容部署为 Hermes Agent 的 `productivity` 类别技能。
3. 在对话中发送视频链接或文件，触发工作流。
